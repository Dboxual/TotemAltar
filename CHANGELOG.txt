  [1.0.17]  2026-05-07
────────────────────────────────────────────────────────────────────────────────
  Codebase cleanup — no gameplay changes.

  Dead code removed:
  - Deleted RecipeManager.java (empty class, crafting replaced by Altar GUI).
  - Removed unreachable capitalize() from TotemActivationListener.
  - Removed getAltarMaterial() from ConfigManager (read non-existent config key).
  - Removed unused org.bukkit.Material import from ConfigManager.

  Bug fixes:
  - /totemaltars giveingredient and givetotem now drop overflow items at the
    target player's feet instead of silently discarding them on a full inventory.
  - Command help text corrected: "grave" replaced with "blast|shadow|storm|swap|guardian"
    (appeared on lines 164, 250, 251 of TotemAltarsCommand).

  PlaceholderAPI expansion:
  - Fixed deprecated getDescription().getVersion() → getPluginMeta().getVersion().
  - Added all six placeholders documented in the guide:
      %totemaltars_cooldown_global%
      %totemaltars_cooldown_bar_global%
      %totemaltars_cooldown_<type>%   (blast/shadow/storm/swap/guardian)
      %totemaltars_cooldown_bar_<type>%
    All reflect the single global cooldown (one cooldown system).

  AltarGUI refactor:
  - Extracted makePane(Material, Component) helper; makeFiller and makePlaceholder
    now share it instead of duplicating ItemMeta boilerplate.

  [1.0.16]  2026-05-07
────────────────────────────────────────────────────────────────────────────────
  Update compatibility — servers can now update by replacing only the jar.

  ConfigMigrator (new):
  - config-version key added to config.yml (current: v1).
  - On startup, detects old config versions and automatically adds missing keys
    with safe defaults; user-set values are never overwritten.
  - Renames keys that changed in prior updates:
      item-names.storm-pearl     → item-names.void-chorus
      item-names.mirrored-shard  → item-names.fractured-echo
      item-names.guardian-crystal → item-names.sentinel-eye
  - Reports all migration actions to the server log.

  ItemMigrationListener (new):
  - On player login, scans the full inventory (main, armor, off-hand).
  - Detects ingredient items whose material changed in an update (e.g. old
    Storm Pearl ENDER_PEARL → current Void Chorus CHORUS_FRUIT).
  - Replaces outdated items with the current version; stack size preserved.
  - Logs each migrated item and notifies the player in chat.
  - If a type is unknown, logs a warning rather than silently discarding.

  ConfigManager fixes:
  - getStormMinDistance() / getStormMaxDistance() fallback defaults corrected
    to 25 / 35 (were still reading 50 / 75 from the old code path).
  - Added getConfigVersion() helper.

  TotemAltars startup:
  - Removed aggressive config.yml deletion on invalid config; migration now
    handles all repair scenarios without data loss.
  - Version now logged on enable using getPluginMeta() (fixes deprecation).

  README:
  - Added Updating section explaining jar-replace workflow.
  - Documents what NOT to delete between updates.
  - Explains migration log messages as normal/expected.

  [1.0.10]  2026-05-05
────────────────────────────────────────────────────────────────────────────────
  - Added global cooldown system: after any totem pops, all totem types are
    locked for a configurable duration (default 30s). Prevents chaining
    different totems back-to-back.
  - New config key: global-cooldown (top-level, default 30)
  - New message key: global-cooldown-message with {seconds} token
  - Global cooldown is checked before per-type cooldown in the event handler.


────────────────────────────────────────────────────────────────────────────────
  [1.0.9]  2026-05-05
────────────────────────────────────────────────────────────────────────────────
  - Fixed Guardian Totem trade exploit: replaced partner UUID storage with a
    shared link ID (UUID) stored in both paired totems.
  - Previously, if Player A traded their linked totem to Player C, popping
    Player C's totem would not destroy Player B's totem because the IDs
    no longer matched. The shared link ID fixes this — the pop logic now
    scans all online players for any totem carrying the same link ID.
  - Updated GuardianListener to generate UUID linkId = UUID.randomUUID()
    at link time and pass it to both createLinkedGuardianTotem() calls.
  - Updated hasLinkedGuardianTotem() to use getGuardianLinkId() instead of
    the removed getGuardianLink() method.

  [1.0.8]  (prior session)
────────────────────────────────────────────────────────────────────────────────
  - Removed Grave/Undead Totem entirely (ingredient, totem, mob drop, ability,
    config entries, messages).
  - Added Guardian Totem:
      - Ingredient: Guardian Crystal (Prismarine Crystals, dropped by Guardian
        mob at 15% chance).
      - Linking: right-click another player while holding an unlinked Guardian
        Totem to pair both players. Each receives a linked totem showing the
        partner's name. Unlinked totem consumed from initiator's hand.
      - Ability (on pop): teleports the linked ally to the popping player's
        location and consumes the ally's linked totem.
      - Rules: one active link per player; no self-linking; both players must
        be unlinked to form a new pair.
  - Added GuardianListener for the right-click linking interaction.
  - Updated TotemActivationListener: reads guardian link ID before the 1-tick
    delay (item consumed after the event fires).
  - Added guardian messages to config.yml.

  [1.0.4]  (prior session)
────────────────────────────────────────────────────────────────────────────────
  - Removed vanilla crafting recipe system (RecipeManager gutted).
  - Added Totem Altar system:
      - Altars are admin-placed via /totemaltars createaltar on any anvil.
      - Locations saved to altars.yml, persisted across restarts.
      - TextDisplay holograms spawned above each altar; respawn on chunk load.
      - Right-click altar anvil opens a 27-slot crafting GUI.
      - GUI slots: 11 = totem input, 15 = ingredient input, 13 = output.
      - Output updates live as items are placed; items returned on GUI close.
  - Added /totemaltars createaltar, removealtar, altar commands.
  - Added AltarManager, AltarListener, AltarGUI classes.
  - Added player command /totemaltars altar to locate the nearest altar.
